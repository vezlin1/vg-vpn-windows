# VG VPN для Windows

Упрощённый VPN-клиент VG VPN на базе [Throne 1.3.2](https://github.com/throneproj/Throne/tree/1.3.2).
Изменения VG VPN начаты 29 октября 2026 года. Исходный код распространяется по GNU GPL v3; исходные уведомления об авторстве сохранены.

## Использование

1. Распакуйте **весь** архив в отдельную папку и откройте `VGVPN.exe`.
2. Нажмите **«Добавить подписку»** и вставьте ссылку из личного кабинета VG VPN.
3. Нажмите **«Подключиться»** рядом с нужным сервером. Windows запросит права администратора для TUN; после разрешения клиент продолжит подключение к выбранному серверу.
4. Нажмите **«Отключиться»** в строке активного сервера для отключения VPN.

HWID передаётся с первого запроса подписки. Обновление подписки выполняется раз в час, пока приложение работает; просроченное обновление выполняется после следующего запуска. Обычный запуск программы не подключает VPN и не требует повышения прав.

Меню **«Дополнительно»** содержит ручное обновление подписок, диагностику, технические столбцы, маршруты и исходные настройки Throne. Кнопка проверки обновлений открывает выпуски **VG VPN**; оригинальная программа Throne поверх этой сборки не устанавливается.

Настройки хранятся отдельно от оригинального Throne, в пользовательском каталоге `VG VPN/config`. Не отправляйте файлы этой папки или полные диагностические журналы посторонним: они могут содержать ссылки подписок и параметры подключения.

## Локальная сборка Windows x64

Требуются Windows 10/11, Visual Studio Build Tools 2022 с компонентами C++ x64 и CMake, Go 1.26 или новее, PowerShell и 7-Zip. GitHub Actions для этого форка отключены; сборка выполняется локально.

```powershell
powershell -ExecutionPolicy Bypass -File script/build_vgvpn_windows.ps1
```

Скрипт проверяет SHA-256 загружаемых зависимостей, собирает интерфейс и сетевое ядро и создаёт `dist/VG-VPN-0.1.0-windows64.zip`. В ядре сохранена проверка запуска из той же папки, имя разрешённой родительской программы изменено на `VGVPN.exe`. Qt 6.11.2 и библиотека Cronet берутся из закреплённых выпусков upstream. Временные зависимости находятся в `.vg-build/` и не входят в Git. Исходники сетевого ядра и его зависимостей доступны в `core/` и в исходном Throne по закреплённому ниже commit.

Основа: `throneproj/Throne`, tag `1.3.2`, commit `9dd4fe9606185c147e46f218cf038b254fbcdc9c`. Брендовые ресурсы VG VPN используются с разрешения владельца бренда для этой сборки; разрешения на сторонний код определяются его лицензиями.
